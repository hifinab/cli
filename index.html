Fresh Ubuntu to AI workstation in one command.

hi installs Claude Code, Codex, omp, herdr and Hermes, wires up ROCm, Docker and NetBird, then checks everything is working. It's a single static binary with no runtime to install.

install

CLI only most people

$ curl -fsSL https://hifin.sh/install.sh | sh

Just the hi binary, checksum-verified, in ~/.local/bin. Update it later with hi update.

Workstation

$ curl -fsSL https://hifin.sh/install.sh | sh -s -- install

Installs hi, then opens a menu to pick the Hifin workstation software for Ubuntu 26.04. No GPU setup, no reboot.

Strix Halo

$ curl -fsSL https://hifin.sh/install.sh | sh -s -- install strix

The same menu with AMD ROCm for Strix Halo checked. Reboot once when it finishes.

// Commands

Small surface, sharp edges.

Each command does one thing and delegates to the native tool underneath.

hi install

Install the workstation software. Offers a hostname change, then asks for sudo once.

hi install strix

Everything above plus ROCm and GPU groups, finishing with a local hardware report.

hi verify strix

Re-run the hardware report after the reboot. Nothing is uploaded.

hi net

Enroll with NetBird. The setup key is read without echo and never lands in shell history.

hi net status · down · reconnect

Check, disconnect or reconnect an enrolled peer without a new key.

hi net expose <port>

Put a web app or webhook receiver on your machine, even on localhost, on a temporary public HTTPS address. Password-protected by default, ends on its own, logs every request.

hi init <template> <dir>

Start a project agents work well in: make check, short agent rules, safe settings and CI. Python, web, service, pipeline, ML and autoresearch (model training, trading strategies) built in, plus your team's own, and --update keeps projects current.

hi q <what you want>

Ask for a shell command in plain words, or chat. The model looks at your files first; you see the command, and what its globs match, before Enter runs it. Uses Claude Code, OpenRouter or any OpenAI-compatible endpoint.

hi agent <task>

Hand a task to Claude Code, Codex, or Hermes. It works without permission prompts in a box, on its own branch, and you get one report back, the same for every agent: what it said, whether it worked, and what changed. --bundle web,office,data adds skills and tools for browsing, documents and data.

hi agent best-of <n> <task>

Run one task in n boxes at once, mixing agents. hi runs your check in each box itself and ranks the results, and you keep one. With --score it runs rounds, autoresearch-style: each starts from the best so far, and hi commits a result only when its score beats it. --then "make results" ends a run with a report of every attempt.

hi box shell · run

Run a shell or a command in a rootless container: the project and nothing else, no credentials, a network that reaches only what you allow, and the Strix Halo GPU if you want it. devcontainer.json sets it up for the whole project.

hi compute

Guided menu to start, reach and stop remote GPU machines on Colab, Hugging Face, RunPod or Shadeform, with lifetime limits.

hi compute stop

Pick a running machine from a list, or all of them, and stop it after confirming.

hi compute run <script.py>

Run a script or container to completion on rented hardware and stream its logs.

hi compute serve <model>

Serve a GGUF model with llama.cpp on a rented GPU and tunnel its OpenAI-compatible API to localhost.

hi connect <server>

Join your team's hi server, which approves and pays for GPUs and serves the team's project templates.

hi data

Search the team's private Hugging Face datasets, models and buckets and download one with hf, or read them straight from code with hi data run. The server keeps the token; your machine never holds one.

hi compute run --data <org>/<name>

Give a cloud job the team's data: the server opens a narrow public address with NetBird for the run, so the job downloads it and can call load_dataset itself, with no Hugging Face token on the machine.

hi skills

Find, install, and update agent skills from skills.sh, pinned and audited, and teach agents to use hi safely.

hi adduser <name>

Create a user who already has render and video access.

hi update

Update hi itself to the latest release, checksum-verified. --check only looks.

hi version

Print the installed version.

Step-by-step instructions, examples and every option: the hi guide.

// Strix Halo

Tested on real silicon.

Exercised on an AMD Ryzen AI Max+ 395 with Radeon 8060S graphics; the final report detects the GPU through both amd-smi and rocminfo.

  1. Run the one-liner above on Ubuntu 26.04 amd64.
  2. Pick a hostname, enter your sudo password, and let it run.
  3. Reboot, then run hi verify strix for the final report.
  4. Run hi net to join the NetBird mesh.
